# Catatan Ritase v29

Aplikasi web offline (PWA) untuk catat ritase dump truck & perkiraan gaji.

## Fitur v29
- Gaji pokok: HK ≤ 28 prorata, HK > 28 full (tidak naik)
- PPh 21: kosong = auto 2,17% × kotor; bisa isi manual + bandingkan slip
- BPJS Kesehatan 1% + JHT 2% × GP penuh
- KM manual per slot + total KM manual untuk gaji
- Dasar KM gaji: PDF / master / manual
- Tampilan mobile (viewport)
